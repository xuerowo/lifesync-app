# LifeSync

LifeSync 是一款幫你戒掉拖延的 Windows 桌面程式。做法只有三步：

1. **把一直拖著的事當成任務**，例如寫報告、運動、整理房間。
2. **把喜歡的事當成獎勵**，例如看一集劇、玩一小時遊戲、吃一份甜點。
3. **遵守一條規則：只有完成任務，才能去做當成獎勵的事。**

完成任務會拿到抽卡券，用券抽出這次可以享受的獎勵。想玩，就得先把該做的事做完；做完了，玩得也心安理得。

除了任務和獎勵，它也有目標、專注計時（番茄鐘的做法：專注一段時間、休息一下，輪流進行）和筆記。資料只存在你自己的電腦上，想放上雲端時會先加密。

## 適合誰用

**特別適合有拖延症的人。** 如果你常常這樣：

- 明知道該做，卻一直拖到最後一刻；
- 一滑手機、一打開遊戲就停不下來；
- 訂了計畫，沒幾天就忘了。

那就把「該做卻一直拖的事」放進任務，把「讓你分心、但你很喜歡的事」放進獎勵。喜歡的事不用戒掉，而是變成做完事才拿得到的獎賞。原本害你拖延的東西，反過來成了推你做事的動力。

**也適合：**

- 需要一點獎勵才有動力的人。完成任務就能抽獎，像玩遊戲一樣慢慢累積。
- 習慣用番茄鐘專心讀書或工作的人。
- 不想把生活紀錄交給別人的雲端服務、在意隱私的人。

**可能不適合：**

- 需要程式強制擋住遊戲、網站的人。LifeSync 只負責記錄和發獎勵，不會鎖住任何東西，「完成任務才能做喜歡的事」這條規則要靠自己遵守。
- 要在手機上用，或希望多台裝置自動同步的人。目前只有 Windows 桌面版，雲端備份要自己按「上傳到雲端」「從雲端還原」。
- 要和別人共用、分派任務的團隊。它是給一個人用的。
- 不想自己打包安裝檔的人。目前沒有提供現成的下載。

## 它怎麼運作

- **三個維度**：維度就是生活的三個面向：成長、健康、幸福。每個任務都屬於其中一個維度。
- **抽卡券**：每個任務可以自己設定完成後給幾張；用「專注計時」專注也會拿到券。
- **成就**：某個維度（或三個加起來）累計完成幾次，就能領你自己寫的獎勵，例如「成長累計 100 次：買一本想看的書」。

```
設定目標 ──► 建立計畫 ──► 加入任務 ──► 完成任務 ──┬──► 維度累計次數 ＋1 ──► 達到次數，領成就獎勵
                                                 └──► 拿到抽卡券 ──────────► 到獎勵庫抽獎
```

## 功能

程式上方有四個分頁。

### 維度

- 每個維度最多 3 個目標，例如「規律作息」。
- 顯示每個維度目前累計完成了幾次。
- 目標達成後移到「已達成的目標」，之後可以按「恢復目標」拿回來（那個維度還沒滿 3 個時）。

### 規劃

| 子分頁 | 用途 |
|---|---|
| 計畫清單 | 建立計畫，在計畫底下加任務。任務有四種：**一次性任務**、**每日任務**、**每週任務**（選星期幾）、**隨時挑戰**（不限次數）。每個任務會標出完成一次可得幾張抽卡券。計畫和任務都可以用左邊的「⋮⋮」拖曳排順序，新增的放最上面。優先任務和停止任務的規則見下面。 |
| 專注計時 | 專注一段、休息一下，輪流進行，規則見下面。 |
| 任務歷史 | 每一次的完成紀錄。忘了打勾可以「手動補登紀錄」。 |
| 週曆 | 一次看一週，每天有哪些任務、做完了沒有。 |
| 生活筆記 | 純文字的隨手筆記。 |
| 行動準則 | 寫下想遵守的原則或習慣。 |

**計畫清單的規則**

- 一次性、每日、每週任務可以勾「設為優先任務」，再用「管理優先順序」排名次。排第一的優先任務做完前，其他任務（隨時挑戰除外）會先鎖住，它所在的計畫會標上「目前優先」。
- 每日、每週、隨時挑戰任務不想再做時，可以按「停止這個任務」：它會移到計畫下方的「已結束」區、標上「已停止」，已完成的紀錄和抽卡券都會保留。之後按「恢復這個任務」就會回到清單。

**專注計時的規則**

- 開始前，勾選這次要做的「成長」維度任務。進行中也可以按「這次要做的任務」旁的「＋」再加，計時不會中斷。
- 專注和休息輪流進行，時間長短可以自己設。也可以開「長休息」，例如每完成 4 輪，休息一次 20 分鐘。
- 時間到會停在 00:00、鈴聲一直響（工作列圖示也會閃），按「開始休息」或「開始專注」才進入下一段。等待的時間不算專注也不算休息。
- 專注結束時可以選「繼續心流」，專注中也可以按 ∞ 進入心流：時間到也不停、接著專注，這段時間一樣算專注時間。
- 切到其他分頁時照常計時，畫面上方會顯示小計時器。電腦休眠的時間照算；程式關掉的時間不算，下次打開時會停在關掉時剩下的時間，按 ▶ 繼續。
- **結束時要按「領取 N 張抽卡券」才會拿到券；按「不領取，直接結束」，這次的券就作廢。** 券數是兩部分加起來：
  - 專注時間（含心流）：第 1 個 50 分鐘給 1 張，第 2 個 50 分鐘給 2 張，第 3 個給 3 張，以此類推。所以 50 分鐘共 1 張、100 分鐘共 3 張、150 分鐘共 6 張，最多算到 300 分鐘、21 張。
  - 這次完成的任務，照各自設定的張數給。

### 獎勵庫

| 子分頁 | 用途 |
|---|---|
| 抽卡大廳 | 用抽卡券單抽（1 張）或十連抽（10 抽只要 9 張）。 |
| 卡池設定 | 設定獎勵和抽中機率，說明見下面。 |
| 待領取 | 抽到但還沒兌現的獎勵。 |
| 抽卡紀錄 | 抽過的所有紀錄。 |
| 成就區 | 分成「總成就」（三個維度加起來）和各維度的成就。每個成就設定「完成幾次任務可以領什麼」，達到就能領取。 |

**卡池怎麼設定**

- 獎勵分成五種稀有度，由低到高是 N（普通）、R（稀有）、SR（超稀有）、SSR（傳說）、UR（神話），卡池設定頁上也有這行說明。每種稀有度的抽中機率可以自己調，五個加起來要等於 100%（預設是 N 50%、R 25%、SR 15%、SSR 8%、UR 2%）。
- 每個稀有度底下放獎勵。獎勵可以是一段文字（例如「看一集喜歡的劇」），也可以用「從資料夾加入圖片」放進一整個圖片資料夾：抽中時從資料夾裡隨機挑一張圖。圖片會複製進程式自己的圖庫；檔名一樣但內容不同的圖片會自動改名，不會蓋掉舊的。

### 設定

- **本機完整備份**：把資料和圖庫一起匯出成一個資料夾，之後可以整份還原。為了安全，備份裡**不含**雲端密碼和主密碼，換電腦還原後要重新輸入雲端設定。
- **雲端加密備份（WebDAV）**：WebDAV 是很多雲端硬碟都支援的連線方式，設定頁有推薦的服務商和設定教學。
  - 「上傳到雲端」用這台電腦的資料整份取代雲端上的備份（不會兩邊合併，所以按下去會先確認）；「從雲端還原」把雲端的備份下載回來。上傳前會用你設定的「資料加密主密碼」加密，雲端服務商看不到內容；雲端上原本那份會先另存成舊版，最多留 5 份。
  - 圖片要另外按「上傳圖庫」「下載圖庫」，一樣會先加密（圖片的檔名不會加密）。兩個按鈕都只補傳對方還沒有的圖片，不會刪除或蓋掉已經有的。
  - 都要自己按，不會自動同步。
- **主密碼請另外記在安全的地方**。它是解開雲端備份的唯一鑰匙，忘了就救不回來。

## 安裝與使用

1. 取得安裝檔 `LifeSync Setup ＜版本＞.exe`（例如 `LifeSync Setup 1.0.0.exe`）。這個專案目前沒有提供現成的下載，要自己打包：先照下方「開發」的「準備」裝好 Node.js、執行 `npm install`，再照「打包安裝檔」執行 `npm run build`。
2. 執行安裝檔，之後從開始選單或桌面捷徑開啟 LifeSync。
3. 也可以用免安裝的可攜版 `LifeSync ＜版本＞.exe`，直接雙擊就能用。

同一時間只能開一個 LifeSync。已經開著時再點一次捷徑，只會把原本的視窗叫到前面，避免兩個視窗互相蓋掉對方存的資料。

### 你的資料放在哪裡

| 使用方式 | 資料夾 |
|---|---|
| 安裝版、可攜版 | `%APPDATA%\lifesync-app\data\`（在檔案總管的網址列貼上這串就能打開） |
| 開發模式、瀏覽器模式 | 專案資料夾裡的 `data\` |

- 資料檔是 `lifesync-data.json`，獎勵圖片在同一層的 `gallery\`。
- 可攜版的資料**不會**跟著 exe 檔走，一樣放在 `%APPDATA%`。
- 安裝版和開發模式用的是兩份不同的資料，互不相通。
- **搬到別台電腦**：複製整個資料夾，或用「本機完整備份」。有兩樣東西不會跟過去：專注計時的時間設定（存在程式裡，不在資料檔），以及雲端密碼和主密碼（只有原本那台電腦解得開），到新電腦要重新設定。
- **更新程式後不要再用舊版開同一份資料**，也不要讓還裝舊版的電腦從雲端下載新資料。新版可能改了資料的格式（例如 2026-11-22 把「學習」改成「成長」），舊版會看不懂。資料不會不見，裝回新版就恢復。

### 資料的保護措施

- **存檔不會存到一半**：先寫到暫存檔，完整寫好才換上去，斷電也不會留下壞掉的檔案。
- **每日自動備份**：每天第一次存檔前，先把原本的資料複製一份到 `backups\`，保留最近 10 份。
- **覆蓋前先拍快照**：「從雲端還原」、匯入資料檔（JSON）、還原完整備份之前，會先跳出確認，再把目前的資料複製一份到 `backups\`（保留最近 10 份）。快照失敗就不會覆蓋。
- **讀不出來時不會亂蓋**：資料檔讀不出來（例如壞掉、不見、被別的程式鎖住）時，程式不會存檔，而是顯示錯誤畫面，讓你選「重試」或「載入最近一次自動備份」。選了載入備份，讀不出來的那個檔案會先改名保留，不會刪除。
- **存檔失敗會提醒**：上方出現紅色提示，並自動重試。

## 開發

以下給想修改程式的人。

### 準備

1. 安裝 [Node.js](https://nodejs.org/)，這是執行這個專案需要的工具。
2. 在專案資料夾執行 `npm install`，下載需要的套件。npm 12 以後的安全設定比較嚴格，專案已經設定好，直接執行即可；原因見 [docs/build-and-packaging.md](docs/build-and-packaging.md)。

### 啟動

最簡單的方式是雙擊 `run.bat`：第一次會自動安裝套件，接著同時開啟兩樣東西：

- 開發版的 LifeSync 視窗；
- 瀏覽器模式：可以用瀏覽器打開終端機上顯示的網址（通常是 `http://localhost:5173`）操作同一份資料。它只接受這台電腦自己的連線，同一個 Wi-Fi 的手機連不進來。

注意事項：

- LifeSync 視窗和瀏覽器寫的是同一個資料檔，**不要兩邊同時修改**，後存的會蓋掉先存的。
- 瀏覽器模式不會在覆蓋前拍快照（確認視窗會直接說明），雲端密碼也是直接存進資料檔、沒有加密。

也可以用指令啟動：

```bash
npm run dev:all   # LifeSync 視窗 + 瀏覽器模式（和 run.bat 一樣）
npm run dev       # 只開 LifeSync 視窗
```

### 測試時不碰真實資料：沙盒模式

沙盒會在暫存資料夾建立一份獨立的資料再啟動程式，怎麼操作都不會動到你的真實資料。

```bash
npm run sandbox                          # 空白資料
npm run sandbox -- --copy-installed      # 複製一份安裝版的資料進來
npm run sandbox -- --copy <資料檔路徑>    # 複製指定的資料檔進來（原檔只讀不寫）
npm run sandbox -- --reuse <沙盒資料夾>   # 沿用之前的沙盒
npm run sandbox -- --browser             # 改用瀏覽器模式，可以和上面的參數一起用
```

- 複製進來的資料會清掉雲端設定，避免不小心連到真正的雲端。
- 只複製資料檔、不複製圖片，所以沙盒裡的獎勵圖片會顯示不出來。
- 沙盒用完不會自動刪除，位置會印在畫面上。
- 原理：程式啟動時如果有 `LIFESYNC_DATA_DIR` 這個環境變數，就改用它指定的資料夾。環境變數是啟動程式前先設定好、讓程式讀取的一個值。

### 檢查

```bash
npm test          # 自動測試
npm run lint      # 檢查程式寫法（目前還有幾個舊問題沒整理完）
```

手動檢查清單在 [docs/manual-checks.md](docs/manual-checks.md)，每一項都寫了怎麼操作、應該看到什麼。

### 打包安裝檔

```bash
npm run build
```

會先清掉舊的 `dist\` 和 `dist-electron\`，再打包。完成後的檔案在 `dist_electron\`（注意是底線，和上面用連字號的 `dist-electron\` 不同）：

- `LifeSync Setup ＜版本＞.exe`：安裝程式（版本號碼是 `package.json` 裡的 `version`）。
- `LifeSync ＜版本＞.exe`：免安裝的可攜版。
- `win-unpacked\`：解開後的程式資料夾。直接開裡面的 `LifeSync.exe` 會讀寫真正的資料；要測試的話，先設定 `LIFESYNC_DATA_DIR`，指令見 [docs/build-and-packaging.md](docs/build-and-packaging.md) 第 4 節。

其他注意事項：

- 打包失敗、訊息有 `Cannot create symbolic link` 時，見同一份文件第 3 節。
- 升級 Electron 後要多做的步驟，也在同一份文件。
- 新增套件時請用 `npm install -D`。畫面和主程序（Electron 在背景負責讀寫硬碟、連雲端的那一部分）用到的套件在打包時就已經整合進去，安裝檔裡不需要再放一份。

### 清理資料裡的舊欄位（小心使用）

`scripts/clean-data.ts` 會刪掉程式已經不用的舊欄位：成就的 `rewardRarity`、`rewardCount`，以及專注紀錄裡任務的 `isPriority`、`priorityOrder`、`learningOrder`。

```bash
node scripts/clean-data.ts --file <資料檔路徑>           # 只預覽，不寫入
node scripts/clean-data.ts --file <資料檔路徑> --apply   # 真的寫入
```

- 加上 `--apply` 時，會先在原檔旁邊複製一份 `<檔名>.before-clean-<時間>.json` 再寫入。刪掉的欄位不會自己回來，要還原只能用這份備份。
- 執行前請先關掉 LifeSync，不然程式下次存檔會把結果蓋回去。

### 使用的技術

- **畫面**：React 19、Tailwind CSS、Framer Motion（動畫）、Lucide（圖示）
- **桌面程式**：Electron 39，把網頁做的畫面包成 Windows 程式，並負責讀寫硬碟。39 系列已經停止更新，之後要另外安排升級，見 [docs/build-and-packaging.md](docs/build-and-packaging.md)。
- **建置與測試**：Vite、electron-builder、Vitest、ESLint
- **瀏覽器模式的資料伺服器**：Express，只在開發時用

### 資料夾說明

| 位置 | 內容 |
|---|---|
| `src/components/` | 各分頁的畫面 |
| `src/domain/` | 遊戲規則與計算，例如抽卡券、專注計時的計時、完成計畫、停止任務；大多有自動測試 |
| `src/shared/` | 畫面和主程序共用的程式，例如預設資料、舊資料轉換 |
| `src/contexts/`、`src/hooks/`、`src/utils/` | 資料狀態與其他共用程式 |
| `electron/` | 桌面程式的主程序；`storage.ts` 負責安全存檔與自動備份 |
| `server.ts` | 瀏覽器模式用的本機資料伺服器 |
| `scripts/` | 沙盒、資料清理、打包前清理等小工具 |
| `tests/` | 自動測試 |
| `docs/` | 手動檢查清單（[manual-checks.md](docs/manual-checks.md)）、重要決策紀錄（[decisions.md](docs/decisions.md)）、打包注意事項（[build-and-packaging.md](docs/build-and-packaging.md)）、手機版計畫（[mobile-plan.md](docs/mobile-plan.md)、[mobile-sync-design.md](docs/mobile-sync-design.md)）、用詞檢視（[wording-review.md](docs/wording-review.md)） |
| `data/` | 開發模式的資料，不會上傳到 GitHub |
